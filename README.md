# Student Task Manager

Simple full-stack practice project:
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: SQLite

## Run backend
cd backend
npm install
npm start

## Run frontend
cd frontend
npm install
npm run dev

Backend: http://localhost:5000
Health: http://localhost:5000/api/health
Frontend: http://localhost:5173

No Docker, Docker Compose, Jenkins or CI/CD files are included intentionally.
